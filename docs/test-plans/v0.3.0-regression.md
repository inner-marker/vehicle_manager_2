# Regression checklist: `v0.3.0`

*The `v0.3.0` release plan (`docs/phase_plans/phase-3.md`), question 3 · plan §9 "Before a release, the relevant plans are re-run as a manual regression checklist" · decisions #062, #070, #079*

A short pass on the **test server** with the **`:dev`** image, **after the release PR (`chore: release v0.3.0`) has merged into `dev`** and before the PR from `dev` into `main`. **Part A** is `v0.2.0`'s web pass, shortened. **Part B** is Phase 3's exit criteria, on the desktop app built from `dev`. It doesn't re-run the milestone plans; it checks that each milestone's main path still works together. A failure is fixed on `dev`, and the pass is run again, before anything reaches `main`.

## Setup

- **The image:** the "Dev image" run for the release PR's merge finished successfully (Actions).
- **On the NAS over SSH,** in the test server's folder (`/volume1/docker/vehicle_manager_test`): `.env` has `VEHICLEMANAGER_IMAGE_TAG=dev` and `VEHICLEMANAGER_TEST_MINUTES=` empty.
- **The desktop app, bundled from `dev`** (the way the household will run it):

  ```sh
  git switch dev
  git pull
  cd crates/app
  dx bundle --platform desktop --package-types app
  ```

  Open the `.app` from `target/dx/app/bundle/macos/` (right-click → **Open** the first time). Sign in to the **test server** as `admin` (choose a PIN if asked).
- **People:** `admin` (the household's Admin), Sam (Driver), and `vera` (Viewer).
- **Devices:** the Mac (the desktop app, and a browser), and the phone's browser.
- **Offline** is **Tailscale off on the Mac**; the phone stays on Tailscale.
- **The main server is untouched** until the release is tagged.

## If a step fails, capture

- **The step's number,** a screenshot, the device and browser (or the desktop app), and who was signed in, in which mode.
- **Desktop:** Diagnostics → the log viewer, **Area: Sync** (Minimum level: Debug), or the log export.
- **Container logs:** `sudo docker logs --since 30m vehiclemanager-test 2>&1`.
- **Never share** a password, a PIN, `.env`, a cookie, a token, `device-credentials.json`, the copy's or a snapshot's file, or a document with personal details on it.
